# iPhone ショートカット作成手順

2本のショートカットを作成する。
- **A. 「日記」**: 平日用。質問を読み上げ→ディクテーション→GASに送信。
- **B. 「日記に追記」**: 共有シートから起動。クリップボードや選択テキストをGASに送信。Gemまとめのコピペ用。

## 共通の準備

GAS Web App の URL と SHARED_TOKEN をメモ。以下のステップで使う。

---

## A. ショートカット「日記」

ショートカットアプリ → 右上「+」→ ショートカット名「日記」。

### アクション

1. **「テキスト」アクション** → 中身に下記を入力（曜日別質問の辞書）:
   ```
   月: 今日の3行ハイライトは？
   火: うまくいかなかったことは？
   水: 今日学んだことは？
   木: 感謝したいことは？
   金: 今週の進捗を一言で
   土: 最近の気分を色で例えると？
   日: 来週やってみたい小さな実験は？
   ```

2. **「現在の日付」アクション** → フォーマット「カスタム」→ `EEEE` （英語曜日）

3. **「テキスト」アクション** → 上のテキストを日本語曜日にマップする辞書を作っても良いが、簡略化のため:
   - 「辞書」アクションでキー: `Monday`〜`Sunday`、値: 上記7つの質問を1つずつ
   - 「辞書から値を取得」で現在の曜日の質問を取り出す

4. **「テキストを読み上げる」アクション** → 入力: 上の質問テキスト → 待機: オン → 早口モードはお好みで

5. **「テキストを入力」アクション**（ディクテーションになる）→ 「入力方法」をディクテーションに → プロンプト: 質問テキスト

6. **「辞書」アクション** で JSON ボディを作る:
   - キー `token` 値 `<SHARED_TOKEN>`
   - キー `text` 値 ステップ5の結果
   - キー `mode` 値 `entry`

7. **「URL」アクション** → GAS Web App URL を入力

8. **「URLの内容を取得」アクション**:
   - 方法: `POST`
   - 要求の本文: `JSON`
   - JSON: ステップ6の辞書

9. **「辞書から値を取得」** → キー `streak` → 結果を変数 `streak` に保存

10. **「通知を表示」アクション** → 内容: `記録しました 🔥 連続 [streak] 日目`

11. **保存** → 設定（i アイコン）→
    - 「Siriで使用」: フレーズ「日記」を登録
    - 「ホーム画面に追加」: アイコンとラベルを設定して追加

### 動作確認
- ホーム画面アイコンをタップ → 質問が読み上げられる → 喋る → 通知が出れば成功
- Drive の `日記_YYYY-MM` に追記されているか確認

---

## B. ショートカット「日記に追記」

Gemまとめをコピーして共有シート or 直接呼び出しで実行する用。

### アクション

1. ショートカット名: 「日記に追記」
2. 設定 → 「共有シートに表示」: オン → 入力タイプ「テキスト」
3. アクション:
   - **「ショートカットの入力を取得」** （共有シート経由のテキスト or クリップボード）
   - **「if 入力がない」** → 「クリップボードを取得」を実行（直接起動用フォールバック）
   - **「辞書」**: `token`, `text` (入力), `mode` = `weekend`
   - **「URL」**: GAS Web App URL
   - **「URLの内容を取得」**: POST + JSON + 上記辞書
   - **「通知を表示」**: `週末レビューを追記しました ✅`

4. 保存。ホーム画面にも追加しておくと、Gemチャットからコピー後すぐ起動できて便利。

---

## C. オートメーション設定（自動リマインダー）

ショートカットアプリ → タブ「オートメーション」→ 「+」→「個人用オートメーション」。

### C-1. 毎日22:00 通知
- トリガー: 時刻 → 22:00 → 毎日
- アクション: 「通知を表示」→ `日記、まだだよ` + 「ショートカットを実行」→ 日記
- 「実行前に尋ねる」: オフ（即実行したいなら）

### C-2. 日曜20:00 「Gem振り返り」通知
- トリガー: 時刻 → 20:00 → 日曜のみ
- アクション: 「通知を表示」→ `日記Gemで今週を振り返ろう` + 「URLを開く」→ Gemini アプリのGem URL（後述のGem作成後に取得）

### C-3. Wi-Fi接続時通知（帰宅検知）
- トリガー: Wi-Fi → 自宅Wi-Fi → 接続時
- アクション: 「通知を表示」→ `帰ったね。日記つけよう`

### C-4. 充電開始時 通知（寝る前の最後の砦）
- トリガー: 充電器 → 接続時
- 条件: 時刻が21:00以降（「if」アクションで現在の時刻と比較）
- アクション: 「通知を表示」→ `寝る前に1分日記`

## トラブルシューティング

| 症状 | 原因 | 対処 |
|---|---|---|
| 通知に `[streak]` がそのまま表示 | 辞書から値を取得していない | ステップ9を再確認 |
| GAS応答が `unauthorized` | トークン不一致 | SHARED_TOKENがGAS側とショートカット側で同じか確認 |
| Docsに追記されない | フォルダIDが間違い | GAS側 `JOURNAL_FOLDER_ID` を再確認 |
| ディクテーション認識が悪い | iOS設定 | 「設定」→「キーボード」→「音声入力」が日本語ON、オフライン辞書ダウンロード済か確認 |
