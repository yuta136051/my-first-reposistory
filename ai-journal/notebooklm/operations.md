# 運用フロー

## 日次（平日: 月〜金）

```
22:00 通知「日記、まだだよ」
  ↓ タップ or "Hey Siri, 日記"
ショートカット「日記」が起動
  ↓ 曜日別の質問が読み上げられる
音声で30秒〜2分話す
  ↓ 確認画面（誤録防止）
GAS が月次Docsに先頭追記 + ストリーク更新
  ↓
通知「記録しました 🔥 連続 N 日目」
```

書けない日は「記録なし」と言うだけでOK。`mode: skip` で送られ、ソフトストリーク（3日以内なら継続）が維持される。

## 週次（日曜）

### 20:00 Gem振り返り
```
通知「日記Gemで今週を振り返ろう」→ タップ
Gemini アプリで「ジャーナリングコーチ」Gem が開く
  ↓ マイク（Live）起動
5問程度の対話、10〜15分
  ↓ 「まとめて」→ Live 終了
テキストモードで「まとめて」→ コードブロック出力
  ↓ コピー → ショートカット「日記に追記」
GAS が月次Docs に【週末レビュー】見出しで追記
```

### 22:30 NotebookLM 週次レビュー
```
NotebookLM「日記」ノートを開く
  ↓
左ペインで該当月のDocsソースをクリックして同期確認（「ソースを更新」ボタン）
  ↓
保存済みプロンプト「週次レビュー」をクリック
  ↓
出力を読む。気になった点はチャットで追加質問
  ↓
重要な気づきは「メモを保存」してノート化
```

## 月初（毎月1日）

```
朝の通知（要設定）or 自分で確認
  ↓
Drive に新しい「日記_YYYY-MM」が前日のエントリで自動生成されている
  ↓
NotebookLM「日記」ノートを開く
  ↓
右上「+ ソースを追加」→ Google Drive → 「日記_YYYY-MM」を選択
  ↓
これで今月分が自動同期対象に
```

**この月初の手動ソース追加は年12回だけ**。ここを忘れない仕組みとして:
- iOS カレンダーに毎月1日の繰り返し予定「NotebookLMにソース追加」を作る
- または GAS側で新規ファイル作成時に push通知を送る拡張も可能（初版では手動）

## 月末（最終日 or 翌月1日）

```
NotebookLM「日記」ノートを開く
  ↓
保存済みプロンプト「月次レビュー」をクリック
  ↓
出力をスクリーンショット or テキストコピー
  ↓ 任意
Audio Overview 生成 → 通勤中に聞く
  ↓ 任意
重要な学びを来月の手帳/Notion に転記
```

## 年末（12月最終週）

```
NotebookLM「日記」ノートを開く
  ↓
全月次Docsがソースに入っていることを確認
  ↓
保存済みプロンプト「年次レビュー」をクリック
  ↓
Audio Overview を「年次総集編」設定で生成（30分前後）
  ↓
来年への申し送り事項3つを来年1月のDocsの先頭に手動で書き写す
```

## トラブル時のリカバリ

| 症状 | 対処 |
|---|---|
| Docsへの追記が反映されない | GAS の「実行ログ」を確認。トークン不一致やフォルダID間違いが典型 |
| NotebookLMの応答が古い | ソースパネルで対象Docsを選択 → 三点メニュー →「ソースを再同期」 |
| ソース上限に近づいた（80超え） | 古い年（例: 3年以上前）の月次Docsをまとめて1ファイルに連結し、ソースを置き換える |
| 連続日数が変な値になった | GAS の `resetStreak` 関数を手動実行してリセット |
| Gemまとめが期待外れ | system-prompt.md を修正 → Gem を更新 → 再対話 |

## 健全性チェックリスト（月1回）

- [ ] 当月の月次Docsがあり、エントリが日付順に並んでいる
- [ ] NotebookLM のソース一覧に当月Docsがある
- [ ] ストリークが想定値に近い（極端なズレなら GAS のプロパティを確認）
- [ ] iOS オートメーションが動いている（通知が来ている）
- [ ] 週末 Gem レビューが少なくとも月2回は実施できた
