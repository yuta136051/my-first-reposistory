# NotebookLM 保存プロンプト集

NotebookLM「日記」ノートの「メモを保存」または「カスタマイズ」に登録しておく。クリック1つで客観フィードバックを得られるようにする。

---

## 週次レビュー（日曜22:30 実行）

```
あなたは私の客観的な観察者です。直近7日分のソース（最新の月次Docs）から以下を分析してください。

1. 感情パターン: ポジティブ/ネガティブの比率、波の形（山谷の時期）
2. 繰り返し言及されるテーマ・人物・場所のTop3
3. 私自身が気づいていなさそうな盲点（過小評価している成果、見えていないストレス源など）
4. 来週試すと良さそうな小さな実験を1つ（実行可能な粒度で）

辛口だが優しいトーンで、合計500字以内。
ソース内の根拠（日付）を必ず添える。
```

---

## 月次レビュー（月末最終日）

```
今月分のソース（該当月のDocs全体）を読み、以下を出力してください。

1. 今月のハイライト: 印象的だった出来事Top5（日付付き）
2. 先月比で改善した点・悪化した点（前月のDocsもソースに含まれているならそれと比較）
3. 繰り返し現れた感情トリガー: 何が起きると私は機嫌が悪く/良くなる？
4. 来月の自分への手紙: 今月の私から来月の私へ、200字

全体で1000字以内。
```

---

## 年次レビュー（12月末）

```
12ヶ月分のソース全部を読み、年次レポートを作ってください。

- 今年のテーマを一言で
- 月別の気分グラフ: 1月〜12月の各月の感情を1-5のスコアで（テキストで）
- 成長した点（具体的な変化と根拠日付）
- 変わらなかった点（来年の課題）
- 来年への申し送り事項: 3つの具体的な実験

合計2000字以内。
```

## アドホック対話用プロンプト集

### 自己理解
```
過去3ヶ月のソースから、私が無意識に避けている話題は何ですか？
出現頻度が極端に少ないけれど、人生に重要そうなテーマを指摘してください。
```

### 意思決定支援
```
過去1ヶ月のソースから、私の意思決定パターンを抽出してください。
- 衝動的に決めた事例
- 慎重に決めた事例
- 後悔した決定とその共通点
```

### ストレス分析
```
直近2週間のソースから、私のストレス源をTop5でランキングしてください。
各項目に発生日付と、その時の私の対処法を添えて。
```

### 関係性マップ
```
過去6ヶ月のソースで言及された人物を頻度順にリストアップし、
各人物について以下を分析してください:
- 言及される文脈の感情トーン（ポジ/ネガ/中立の比率）
- 私との関係性の変化（時系列で）
```

## Audio Overview 用シードプロンプト

NotebookLMの「Audio Overview」生成時、`Customize` で以下を指定すると個人ポッドキャスト風になる:

```
私の日記を題材に、二人のホストが親しみやすく語り合うポッドキャスト形式で。
- ホスト1: 客観的な分析役（やや辛口）
- ホスト2: 共感的な聞き手役
内容: 直近2週間のハイライト、感じた感情の波、見えてきたパターン、来週の小さな実験提案
時間: 8〜10分
雑談すぎず、本人が通勤中に聞いて「あ、確かに」と気づける深さで。
```

---

## 運用Tips

- **プロンプトはノートの「保存されたメモ」セクションに置く**（NotebookLMのSaved notes機能）→ クリックで右パネルに展開できる
- 週次/月次プロンプトは毎週同じ文言で構わない → ソースが更新されるので結果は毎回新しい
- 出力に納得いかない時は「もっと辛口で」「日付を明示して」等の追加指示で再生成
