# 「ジャーナリングコーチ」Gem セットアップ手順

## 1. Gem 作成
1. Gemini アプリ or https://gemini.google.com を開く
2. サイドバー「Gem マネージャー」→「新しい Gem」
3. 名前: `ジャーナリングコーチ`
4. 説明: `週末の音声振り返り専用。5問以内で深掘り→まとめ出力。`
5. 指示欄: `gem/system-prompt.md` の本文（`---` で挟まれた部分）をそのまま貼り付け
6. 保存

## 2. Gem URL を取得
1. 作成後、Gem を開く
2. ブラウザの URL をコピー（`https://gemini.google.com/gem/XXXXXXXX` 形式）
3. iPhone ショートカット C-2（日曜20:00通知）の「URLを開く」アクションにこの URL を貼る

## 3. 初回テスト
1. Gemini アプリで「ジャーナリングコーチ」を開く
2. **テキストモードで先にテスト**: 「先週の振り返りを始めて」と入れる
3. 質問が来ることを確認 → 適当に2-3回答 → 「まとめて」と入力
4. 指定フォーマットのコードブロックが出るか確認
5. 出力がズレている場合は `system-prompt.md` を調整して Gem を更新

## 4. Live モードで実運用テスト
1. Gem画面右下のマイクアイコン（Live モード）をタップ
2. Gem が話し始めるのを待つ
3. 音声で対話 → 終わったら「まとめて」と発話
4. Live を終了 → 同じスレッドにテキストで「まとめて」と入力（Live中は出力フォーマットが崩れることがあるため、テキストで再出力させる）
5. 出力されたコードブロックの中身をコピー
6. iPhone のショートカット「日記に追記」を起動 → クリップボードから送信
7. Drive の `日記_YYYY-MM` に `【週末レビュー】` 見出しで追記されているか確認

## 5. 日曜運用のフロー

```
20:00 通知 「日記Gemで今週を振り返ろう」
  ↓ タップ
Gemini アプリ で「ジャーナリングコーチ」が開く
  ↓ マイクアイコンで Live 起動
10〜15分対話
  ↓ 「まとめて」
Live 終了 → テキストで「まとめて」
  ↓ コードブロックをコピー
ショートカット「日記に追記」起動
  ↓ 自動送信
Drive の月次 Docs に追記完了 通知
  ↓
22:30 NotebookLM で週次プロンプト実行（オプション）
```

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| Gem が質問を5つ超えて続ける | system-prompt の「禁止事項」を強調 or 「合計5問で必ず終わる」と明示 |
| まとめの形式が崩れる | Live 中ではなく Live 終了後にテキストで「まとめて」を入力 |
| Live が日本語で起動しない | Gemini アプリの言語設定を日本語に |
| コードブロックでなく地の文で出力される | プロンプト先頭に「常にコードブロックで出力」を追記 |
